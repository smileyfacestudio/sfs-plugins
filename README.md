# SFS Audio plugins

Free downloads of the Smiley Face Studio plugins, for macOS.

Each download is the whole plugin. Until you add a license, the sound dips for a moment once a minute. You can buy a license at [smileyface.studio](https://www.smileyface.studio/products).
